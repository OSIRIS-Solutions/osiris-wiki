# Authentifizierung verwalten

Auf dieser Seite kannst du bestimmen, wie sich Nutzende in eurer Instanz registrieren können. Wenn die **Selbstregistrierung** gewählt wird, kann jede Person, die eure Produktionsinstanz besucht, einen Account erstellen. Dies kann leicht zu unauthorisiertem Zugriff führen.

Der **Authentifizierungs-Token** gibt dir die Sicherheit, dass sich nur Personen, die über den aktuellen Token verfügen, in eurer OSIRIS-Instanz anmelden können. Der Token kann geändert werden, sodass Personen, die nur über eine alte Versionen des Tokens verfügen, sich nicht mehr registrieren können.

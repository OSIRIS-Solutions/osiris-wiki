# Manage Authentication

On this page, you can configure how users can register for your instance. If **Self-registration** is enabled, anyone who visits your production instance can create an account. This can easily lead to unauthorized access.

The **Authentication Token** ensures that only people who have the current token can register with your OSIRIS instance. The token can be changed at any time, preventing anyone who only has an outdated version of the token from registering.

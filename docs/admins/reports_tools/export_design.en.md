# Export Design

In OSIRIS, you can export data in various places, such as Word reports or CVs. On this page, you can customize the design of these exports.

You can adjust the font family and base font size used for the **General Typography**, as well as the font size and color of the different **heading levels**.

For **tables** in your exports, you can configure the border color, border width, and row spacing. You can also customize the **page layout**, edit the **footer**, and choose whether page numbers should be included.
